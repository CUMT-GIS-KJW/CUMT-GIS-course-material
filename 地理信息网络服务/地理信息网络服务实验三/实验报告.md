# Node.js 简易留言板实验报告

## 1. 上机目的

了解并掌握 Node.js 的基本开发方法。使用 HTML、CSS、JavaScript 作为前端，Node.js 和 Express 作为后端，使用 MySQL 数据库管理系统，构建一个简单留言板 Web 应用。

## 2. 上机软件环境

- 操作系统：Windows 11
- 编辑软件：VSCode
- 调试工具：浏览器、Node.js、npm、MySQL
- 后端框架：Express
- 数据库驱动：mysql2
- 密码加密：bcryptjs
- 登录状态管理：express-session

## 3. 系统功能

本系统实现了以下功能：

- 用户注册：新用户输入用户名和密码完成注册，密码使用 bcrypt 加密保存。
- 用户登录：已注册用户可登录系统，登录状态由 Session 保存。
- 用户退出：登录后可退出当前账号。
- 发布留言：登录用户可发布留言。
- 评论留言：登录用户可在自己或其他用户发布的留言下发表评论。
- 展示留言：系统展示留言及其评论。
- 删除留言：用户只能删除自己发布的留言或评论。
- 搜索留言：可按用户名或留言内容进行前端搜索。
- 筛选留言：可查看全部留言或“我的参与”。
- 数据库状态：页面显示 MySQL 连接状态、用户数量、留言数量和评论数量。

## 4. 数据库设计

数据库名称为 `message_board`，包含两张表：

- `users`：保存用户信息，包括用户名、加密后的密码和注册时间。
- `messages`：保存留言和评论，`parent_id` 为空时表示主留言，不为空时表示评论。

后端启动时会自动检查 MySQL 连接，创建数据库和数据表。数据库初始化脚本位于 `database/schema.sql`。

## 5. 主要实现

前端文件位于 `public` 目录：

- `index.html`：页面结构。
- `styles.css`：页面样式。
- `app.js`：前端交互和接口请求。

后端入口文件为 `server.js`，主要接口如下：

- `GET /api/health`：检查 MySQL 连接和统计信息。
- `POST /api/register`：用户注册。
- `POST /api/login`：用户登录。
- `POST /api/logout`：退出登录。
- `GET /api/session`：获取当前登录状态。
- `GET /api/messages`：获取留言列表。
- `POST /api/messages`：发布留言。
- `POST /api/messages/:id/comments`：评论留言。
- `DELETE /api/messages/:id`：删除留言或评论。

## 6. 运行步骤

安装依赖：

```bash
npm.cmd install
```

检查 `.env` 中的 MySQL 配置：

```text
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_NAME=message_board
```

启动项目：

```bash
npm.cmd start
```

浏览器访问：

```text
http://localhost:3000
```

## 7. 实验总结

通过本实验，完成了 Node.js 项目的基本搭建，掌握了 Express 路由、Session 登录状态、MySQL 数据库连接、自动建库建表、前后端接口交互等基础开发流程，并实现了一个具备注册、登录、留言、评论、展示、删除、搜索、筛选和数据库状态展示功能的简易留言板系统。
